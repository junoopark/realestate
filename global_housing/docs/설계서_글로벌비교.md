# 서울을 포함한 글로벌 도시 주택시장 비교 분석 설계서와 코딩 실행 프롬프트

작성일 2026년 11월 4일

## 1 연구 목표와 권고 범위

서울의 매매가격과 임대료가 해외 주요 도시 대비 어느 수준인지, 소득 및 임대료 대비 구매가격 부담이 큰지, 각 도시의 과거 추세와 비교해 불균형이 확대됐는지를 분석한다. UBS Global Real Estate Bubble Index 2026을 참고하되, 독립적으로 수집한 자료와 공개된 계산 규칙으로 재현 가능한 분석을 만든다.

기본 표본은 **서울과 해외 10개 도시로 총 11개**다. 도시 수보다 지역 범위와 주택 유형의 정합성을 우선한다. 최신 수준 비교는 횡단면 분석이지만, 도시별 장기 추세 대비 평가에는 시계열이 필요하다. 따라서 최신 횡단면과 연간 패널을 함께 구축한다. 11개 도시만으로 다수 설명변수를 넣는 횡단면 회귀를 핵심 결과로 삼지 않는다.

핵심 산출물은 도시별 수준 비교표, 가격·임대료·소득의 상대 경로, 서울 심층 분석, 데이터 출처표, 재실행 가능한 Python 프로젝트다. 합성지수는 데이터 확보 이후의 선택 산출물로 둔다.

## 2 UBS 원문에서 확인한 기준

원문 PDF의 인쇄 페이지와 파일 페이지는 모두 26페이지가 방법론, 27페이지가 출처표다. 27페이지는 기관 목록이며 실제 API 주소나 개별 시계열 코드까지 제시하지는 않는다.

UBS의 다섯 구성요소는 가격 대비 소득, 가격 대비 임대료, 도시 대비 전국 가격, 주택담보대출 대비 GDP의 변화, 건설 대비 GDP의 변화다. 국가 지표 두 개와 도시 지표를 결합하며, 가중치에는 요인분석과 제약을 적용한다. 홍콩·싱가포르·두바이에는 도시 대비 전국 가격 대신 실질가격을 사용한다. 별도 수준 비교에는 도심 인근 60㎡ 주택과 숙련 서비스업 근로자의 소득을 사용한다. 자체 조사와 유료 자료도 포함한다. 서울의 출처는 한국은행과 FISIS로 기재되어 있다. [S1, pp. 26–27]

**이 프로젝트의 구분:** UBS가 사용한 기관, 이번 프로젝트에서 선택한 원자료, 공개자료로 대체한 지표를 별도 열로 기록한다. 원문에 없는 세부 계산창·계열 코드·가중치를 추정해 UBS의 확정 방법론처럼 제시하지 않는다. 같은 수치의 완전 복제를 보장하지 않는다.

## 5 지표 정의와 계산 규칙

### 5.1 현재 수준 지표

P는 주택 가격, R은 같은 유형·지역·면적의 월 임대료, Y는 연간 소득이다. 가능한 한 같은 관측연도와 모집단을 사용한다.

| 지표 | 계산 | 단위와 해석 |
|---|---|---|
| 대표 주택 가격 | 가격/㎡ × 60㎡ | 현지통화, 면적 조정이 타당할 때만 |
| 소득 대비 가격 PIR | P / Y | 소득 몇 년분인지, 개인·가구를 따로 표기 |
| 임대료 대비 가격 PTR | P / (12 × R) | 연 임대료 몇 년분인지 |
| 총임대수익률 | 12 × R / P × 100 | %, 비용·공실·세금 차감 전 |
| 소득 대비 임대료 | 12 × R / Y × 100 | %, 소득 정의를 PIR과 일치 |
| 단위면적당 가격·임대료 | P/㎡, R/㎡ | 현지통화, USD 환산을 보조로 제공 |

기본 소득 개념은 비교 가능한 연간 가구 가처분소득으로 검토하되, 모든 도시에 확보되지 않으면 세전 가구소득 등 일관된 별도 패널을 만든다. 숙련근로자 개인소득을 확보한 경우 UBS와 유사한 보조 패널로 제시한다. 서로 다른 개념을 한 순위표에 섞지 않는다. GDP/인구는 가구소득이나 임금의 대체값으로 기본 PIR에 넣지 않는다.

60㎡가 곤란한 경우 50–70㎡ 등 유사 구간의 아파트를 사용하고 면적 범위를 표시한다. 침실 수만 있는 자료를 근거 없이 60㎡로 환산하지 않는다. 매매가 중간값과 임대료 중간값의 비율은 동일 주택의 수익률이 아니라 시장 대표값의 근사임을 명시한다.

시장환율 USD는 국제 구매자의 금액 비교, 국가 소비 PPP 환산은 생활비 관점의 보조 비교다. 국가 PPP는 도시별 주거 구매력의 정확한 조정치가 아니다. 현지통화 PIR·PTR이 주된 비교 지표다.

### 5.2 경로와 과거 대비 평가

연간 자료를 공통 분석의 기본 주기로 삼는다. 가능한 도시는 분기·월 자료도 보존한다. 2005년 이후를 목표로 하되 공통 표본기간은 실제 수집 결과로 결정한다. 충분한 자료가 있는 도시만 10년 변화와 장기 평가에 포함한다.

- 실질가격지수 = 명목가격지수 / CPI × 상수. 임대료와 소득도 같은 방식으로 실질화한다.
- 전년 대비 실질 변화 = (실질지수_t / 실질지수_t-1 − 1) × 100. 원자료가 분기면 t-4다.
- 5년·10년 변화는 누적 변화와 CAGR을 구분한다. CAGR = [(지수_t / 지수_t-k)^(1/k) − 1] × 100.
- 상대 PTR 지수 = (가격지수_t / 임대료지수_t) / (가격지수_b / 임대료지수_b) × 100.
- 상대 PIR 지수도 동일 방식으로 소득지수를 사용한다. 이는 연수로 표시되는 PIR과 다르다.
- 도시 집중도 = (도시가격지수_t / 전국가격지수_t) / (도시가격지수_b / 전국가격지수_b) × 100. 이는 도시 주택이 전국의 몇 배 비싼지를 뜻하지 않는다.
- 홍콩·싱가포르처럼 도시와 국가가 사실상 중첩되는 경우 도시/전국 항목을 생략하고 실질가격 괴리를 별도로 표시한다.

월별 가격·임대 지수와 CPI는 연평균을 기본으로 한다. 수준 자료는 해당 통계의 대표기간을 유지하고 시점을 표시한다. 연말 대출잔액/연간 명목 GDP는 %로 계산한다. 건설투자/연간 GDP는 명목 흐름끼리 계산한다. 건설업 부가가치·건설투자·주거투자는 서로 다른 개념이므로 혼합하지 않는다.

기준연도 b는 공통 관측이 확보된 연도에서 선택한다. 2015년을 우선 검토하되 불가능하면 2019년 등으로 변경하고 변경 이유를 남긴다. 장기 표준화 결과는 최소 10개 연간 관측을 요구한다. 단기계열은 수준·변화표만 제공하고 장기 z-score에서 제외한다.

### 5.3 서울 보증금과 전월세 처리

전세 보증금/매매가 비율을 PTR이라고 부르지 않는다. 전세와 월세는 별도 항목이다. 보증부 월세의 환산 월 임대료는 다음과 같다.

`환산 월 임대료 = 계약 월세 + 보증금 × 연 환산율 / 12`

연 환산율은 보증금 기회비용을 월 현금흐름으로 환산하기 위한 연구 가정이다. 기준 시점의 공신력 있는 금리나 관측된 전월세 전환율을 검토하되, 법적 상한을 시장 전환율로 자동 사용하지 않는다. 기준값과 ±1%p를 제시하고, 보조로 2·4·6% 시나리오를 비교한다. 계약건별 환산 후 면적·지역을 맞춰 집계한다.

R-ONE 월세지수의 보증금 처리와 표본 정의를 확인한다. 이미 환산된 지표에 보증금 조정을 다시 적용하지 않는다. 월세 수준을 확보하지 못하면 임대수익률·절대 PTR을 계산하지 않고 상대 PTR 지수만 제공한다.

실거래 기반 서울 분석은 신규·갱신, 전세·월세, 아파트·비아파트를 분리한다. 계약일을 사용하고 취소·해제, 신고 지연, 중복, 면적·층·준공연도·지역별 구성 변화를 점검한다. 신고제 전후 수집 범위 변화를 처리한다. 단순 거래 중간값 변화를 순수한 가격상승률로 단정하지 않고, 고정된 지역·면적 가중 또는 헤도닉 보정을 보조로 검토한다.

## 6 합성지수와 설명변수의 범위

### 6.1 기본 산출물은 지표별 대시보드

11개 도시의 횡단면 z-score만으로 UBS의 위험등급을 복제하지 않는다. 횡단면 z-score는 표본 내 상대 위치이고, 역사적 불균형이나 가격하락 확률이 아니다. 임계값 0.5·1.0·1.5를 자체 지수에 그대로 적용하지 않는다.

독립 합성지수는 선택적으로 다음 규칙을 사용한다. 이 규칙은 본 프로젝트의 제안이며 UBS의 원식을 뜻하지 않는다.

1. 연간 지표를 도시별 과거 자료로 표준화한다. 기본 비교 기준은 최소 10년의 공통 고정기간으로 설정하고 평균·표준편차·관측 수를 저장한다.
2. 기본 구성은 가격/소득 상대지표, 가격/임대료 상대지표, 도시/전국 상대지표, 주택담보대출/GDP의 3년 변화, 건설투자/GDP의 3년 변화다. 마지막 두 변화 단위는 %p다.
3. 기본 가중치는 앞의 도시 항목 세 개에 각각 2/9, 국가 항목 두 개에 각각 1/6로 둔다. 국가 항목 합계는 1/3이다.
4. 도시/전국이 부적절한 도시에는 실질가격 괴리를 사용하되 구성 차이를 표시하고 해당 도시를 제외한 민감도 결과도 제공한다.
5. 결측 구성요소가 있으면 해당 도시의 전체 점수는 NA다. 임의의 가중치 재배분으로 완전한 점수처럼 표시하지 않는다. 별도의 2항목 공통 패널은 명칭을 달리한다.
6. 3년 변화 대신 1년·5년 변화, 평균·표준편차 대신 중앙값·MAD, 대체 임대료 및 가중치 변화에 대한 순위 민감도를 확인한다. MAD가 0이면 점수를 NA 처리한다.
7. 요인분석은 장기 패널과 충분한 관측이 있을 때만 확장한다. 11개 도시의 한 시점 자료로 도시별 요인 가중치를 추정하지 않는다.

비교 시계열의 고정 기준기간은 사후 비교용이다. 예측·조기경보 실험을 추가하면 매 시점에 실제 이용 가능했던 과거 자료만 사용해 평균·분산·모형을 다시 추정한다. 가격하락에 대한 별도 검증 없이 점수를 확률이나 조기경보 성능으로 해석하지 않는다.

### 6.2 회귀는 확장 분석

인구밀도·순이동·가구 수·공급·소득·금리·가계부채는 설명 후보로 수집하되, 기초 비교 완성 뒤 활용한다. 11개 도시 단일 횡단면은 산점도와 기술통계 위주로 제시한다. 패널 자료가 충분하면 로그 PTR 또는 로그 PIR을 종속변수로 하는 도시·연도 고정효과 모형을 탐색한다.

국가 금리·가계부채는 동일 국가 도시들에 반복되는 값임을 인식한다. 적은 도시·국가 클러스터에서 통상적인 유의확률은 불안정하므로 클러스터 수와 추론 제약을 보고한다. 수준의 구조적 차이와 도시 내부 변화를 구분하고, 고정효과 잔차를 서울의 적정가격이나 인과효과로 해석하지 않는다.

## 7 데이터 확보와 시점 통제

분석 기준일은 2026년 11월 4일로 설정한다. 이후 재실행할 수 있도록 설정 파일에서 변경 가능하게 한다. 기준일까지 공표된 자료만 기본 분석에 사용한다. 원자료 수정본으로 과거를 재구성한 분석은 발표 당시 자료를 사용한 빈티지 분석과 구분한다.

최신 공통연도는 자료 확보 후 결정한다. 도시별 최신 자료를 한 표에 제시할 때는 관측기간과 발표일을 열로 표시하고, 공통연도 표와 분리한다. 소득이 1~2년 늦으면 가격도 같은 연도로 맞춘 것을 기본으로 하고 소득 추정치는 보조표로만 제시한다.

공식 API·CSV·XLSX를 우선하고 PDF는 차선으로 사용한다. PDF에서 수작업 전사하면 페이지·표·원문값·단위와 추출 방식을 남긴다. API 키가 없는 경우 수동 다운로드 경로와 입력 양식을 제공한다. 유료 데이터나 인증이 필요한 자료를 확보한 척하지 않는다.

국제기구 자료의 역할은 다음과 같이 제한한다.

| 기관 | 우선 용도 | 확인할 제약 |
|---|---|---|
| BIS | 전국 가격, 부문별 신용의 보조 검증 | 가계신용 전체는 주택담보대출과 다름 |
| OECD | 전국 주택가격·임대·소득 지표, 국민계정, 일부 지역통계 | 지수와 수준을 구별하고 지역 커버리지 확인 |
| IMF | GDP·물가 및 확보 가능한 금융통계 | 주택담보대출의 정의와 장기 연속성 확인 |
| World Bank | PPP·환율·국가 인구 등 보조 변수 | 국가 인구밀도를 도시 인구밀도로 대체하지 않음 |
| 각국 통계청·중앙은행 | 도시 지표와 국가 신용·건설의 핵심 원자료 | 계열 단절·지역 경계·주택 유형 일치 확인 |

일반 가계부채밖에 없으면 mortgage_to_gdp 필드에 넣지 않는다. 별도 household_credit_to_gdp로 저장한다. 주택담보대출 수치와 혼합한 국제 순위는 만들지 않는다.

## 8 데이터 사전과 품질 관리

원자료는 변경하지 않고 보존한다. 표준 데이터는 long format으로 만든다.

필수 필드:

`city_id, country_code, geography_name, geography_code, geography_type, variable, period, frequency, value, unit, currency, price_basis, dwelling_type, tenure_type, area_basis, income_concept, source_id, source_url, series_code, release_date, retrieved_at, vintage, method, quality_flag, notes`

지역·주택유형·소득개념이 달라지면 같은 변수명으로 조용히 연결하지 않는다. 도시별 자료 선택은 configs에 명시한다. 원자료의 기관명·통계표·세부 항목·단위·면적·관측 범위·다운로드 위치·접근 제한을 source_catalog에 저장한다.

품질 등급은 A=정의와 범위가 일치하는 원자료, B=공식 자료이나 일부 불일치 또는 공개 민간 대체, C=추정·범위 불일치가 큰 보조자료로 둔다. 공식 자료라도 모집단이 맞지 않으면 A가 아니다. 등급은 근거와 함께 부여한다.

검증 항목은 중복 키, 결측, 단위 배율, 월/연 환산, %와 %p, 지역 코드, 면적 기준, 신규/기존 임대, 공표일, 소득 분모, 국가와 도시 혼용이다. 0·음수 가격, 비정상 도약은 로그에 남기고 원자료와 대조한다. 결측을 0으로 채우거나 임의 보간해 순위를 완성하지 않는다.

## 9 구현 사양

Python 3.11 이상을 기준으로 하고 실제 검증한 버전을 기록한다. pandas·numpy·requests/httpx·openpyxl·matplotlib 또는 plotly·pyarrow를 기본 후보로 사용한다. statsmodels·scikit-learn은 확장 분석에만 필요하다. 사용한 패키지 버전을 고정한다.

권장 구조:

```text
housing_comparison/

  configs/project.yaml
  configs/cities.yaml
  configs/series.yaml
  data/raw/
  data/manual_inputs/
```

동일한 실행으로 수집 → 정제 → 검증 → 지표 → 도표 → 내보내기가 이어지게 한다. 최소 명령 예시는 다음과 같다. 구현한 실제 CLI와 README의 명령이 일치해야 한다.

```bash
python -m src.run --config configs/project.yaml --stage all
python -m src.run --config configs/project.yaml --offline
python -m pytest
```

HTTP 재시도·시간제한·캐시·호출 제한을 처리한다. 네트워크 실패는 데이터 부재와 구분한다. .env.example에는 키 이름만 넣고 실제 키를 저장하지 않는다. 오프라인 실행은 확보한 원자료로 결과를 재생성한다.

검증용 작은 인공 자료는 tests 안에만 둔다. 실제 분석 데이터로 혼입하지 않는다. PTR과 수익률의 역수 관계, 보증금 환산, CAGR, %p 변화, 공통 기준연도 재지수화, 지역·면적 불일치 차단을 검사한다.

완료 조건은 서울 필수 포함, 도시·변수별 출처 추적 가능, 공통연도와 최신시점 분리, 수준/지수 및 국가/도시 구분, 서울 보증금 민감도, 실제자료 기반 결과, 오프라인 재실행 성공, 핵심 계산 검증 통과다. 합성지수나 회귀가 미완성이어도 핵심 비교는 먼저 완성한다.
