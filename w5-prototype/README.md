# KHMI AI · 5주차 중간발표 자료

금융빅데이터분석실습(KAIST 디지털금융MBA) 4조 · 권태혁 · 노경수 · 박민영 · 박준우

2026년 11월 25일 5주차 아이디어·UI 프로토타입 공유 때 발표한 자료입니다. 발표 때 배포한 파일을 그대로 옮겼습니다.

## 배포 주소
- 발표 페이지: https://khmi-w5.vercel.app/pitch/ (← → 이동, F 전체 화면)
- 프로토타입: https://khmi-w5.vercel.app

## 파일 구성
| 파일 | 화면 |
|---|---|
| `index.html` | 홈 |
| `region.html` | 지역 브리핑 › 지역 동향 |
| `forecast.html` | 지역 브리핑 › 예측 지표 |
| `policy.html` | 정책 브리핑 |
| `zone.html` | 규제지역 지도 |
| `ask.html` | AI 챗봇 |
| `pitch/index.html` | 발표 페이지(11장), 화면 캡처는 `pitch/img/` |
| `dc-lite.js`, `morphdom.min.js` | 지도 클릭, 목록, 검색, 추천 질문, 슬라이더를 움직이는 작은 실행기 |

## 알아 둘 점
- 정적 HTML입니다. 서버·DB·LLM을 호출하지 않고, 숫자는 HTML 안에 넣어 두었습니다.
- 기준: 지표 2026년 10월(전월세전환율·미분양 2026년 9월), 정책 발표 2026년 11월 21일까지.
- AI 문장, 정책 평가, 예측값은 시연용 예시입니다.
- 출처는 화면 각 영역에 표기했습니다(한국부동산원 지수, 정책 원문 링크 등).
- 화면 원본(디자인 파일)과 빌드 스크립트는 들어 있지 않습니다.
