# 상세 이용 통계

`/usage.html`에서 지표별 다운로드, 차트 열람, 정책 상세 열람과 원문 클릭을 비교한다. About → 이용 통계에서 접근한다. 기존 GitHub·Vercel·Render·Supabase 구성 안에서 동작하며 별도 유료 분석 API를 사용하지 않는다.

## 측정 기준

| 지표 | 기록 시점 | 중복·범위 |
|---|---|---|
| 다운로드 | 로그인 사용자가 CSV·XLSX를 내려받는 기존 동작 | 다운로드 작업마다 1회. 지표·지역 단위·지역 목록·형식·기간을 기존 `activity_logs`에 보관 |
| 차트 열람 | 차트 또는 지도가 화면에 50% 이상, 활성 탭에서 연속 2초 표시 | 동일 탭 세션·동작·지표 대상은 1회. 지도와 차트, 지역 단위를 구분 |
| 정책 상세 | 주요 정책이나 정책 히스토리 카드를 사용자가 펼침 | 동일 탭 세션·정책 1회. 단순 목록 노출은 집계하지 않음 |
| 정책 원문 클릭 | 정책 상세·모니터·히스토리의 원문 링크 클릭 | 상세 열람과 별도로 1회. 외부 사이트에서 실제로 글을 읽었는지는 측정하지 않음 |

조회 이벤트는 로그인 없이도 기록하며 기존 로그인 기록과 별개의 탭별 임의 UUID를 쓴다. 동일한 공식 URL의 주요 정책·모니터·히스토리 기록은 서버에서 하나의 정책으로 합친다. 홈의 정책 제목은 정책 목록으로 이동하므로 그 클릭을 개별 정책 열람으로 간주하지 않는다.

## 해석할 때

- 7·30·90일은 한국 시간의 오늘을 포함한다. 다운로드 순위와 일별 집계에 동일한 기간을 적용한다.
- 차트·정책 조회는 계측 도입 시점부터 수집한다. 도입 전 기간은 관측값이 없으며 과거 조회를 복구하거나 다운로드로 추정하지 않는다.
- 조회의 탭 세션 수와 다운로드의 로그인 사용자 수는 서로 다른 기준이다. 합쳐서 전체 방문자 수로 표현하지 않는다.
- 지역별 다운로드는 한 파일에 여러 지역이 포함되면 각 지역에 한 번씩 반영된다. 지역 합계는 다운로드 작업 수보다 클 수 있다.
- 브라우저 추적 거부(DNT)·GPC, 스크립트 차단, 네트워크 오류에 따라 조회 기록이 누락될 수 있다. 노출·클릭은 관심 신호이며 실제 정독이나 투자 의도를 의미하지 않는다.
- 목록 순위는 요청한 상위 개수까지 표시한다. 모든 측정값은 실제 집계이며 빈 화면을 예시 수치로 채우지 않는다.

## API와 저장

- `GET /usage?days=30&top=50`: 기존 로그인·다운로드 응답과 함께 지표/정책 조회 순위, 일별 집계, 다운로드 형식·지역 분해를 반환한다. 서버·CDN 캐시 때문에 최근 기록의 반영에는 지연이 있을 수 있다.
- `POST /usage/events`: 최대 20개 이벤트를 받는다. 세션 UUID, 이벤트 UUID, 허용된 동작, 대상 ID, 화면 구분만 입력한다. 제목·기관·원문 URL은 서버가 검증한 자료에서 결정한다.
- `usage_events`는 `event_id` 기본키와 `(session_id, event, target)` 유일 제약을 사용한다. 재전송과 같은 탭의 반복 열람을 중복 저장하지 않는다. 로그인 사용자 ID·이메일·IP·사용자 에이전트는 이 테이블에 저장하지 않는다.
- 기존 `activity_logs`는 그대로 유지한다. 새 테이블은 서버 시작 시 생성하고 RLS 및 브라우저 직접 접근 제한을 적용한다. 수동 SQL은 `database/migrations/004_usage_events.sql`을 참고한다.
- 공개 응답은 합계와 순위만 포함한다. 개별 이벤트, 세션 ID, 로그인 사용자 ID는 반환하지 않는다.

## 운영과 검증

계측은 GitHub Actions 주기와 관계없이 화면에서 발생한 동작을 API로 전달한다. Actions의 정량·정책 수집 스케줄은 그대로 유지한다. 수집 요청 실패는 사용자의 차트·다운로드·정책 탐색을 막지 않는다.

검증은 격리된 로컬 DB에서 이벤트 수신·기간 경계·재전송 중복·정책 URL 통합·개인 식별 정보 미노출을 확인한다. 브라우저 검사에서는 보이지 않는 차트·2초 미만 표시·반복 렌더·추적 거부 설정을 확인한다. 운영 환경에 가짜 이용 이벤트를 넣어 순위를 채우지 않는다.
